# Mapas de estudio

Mapas de estudio interactivos por materia, con todo el contenido de las clases, la clase y diapositiva de cada tema, los versículos citados (Reina-Valera 1909, con enlace a la RVR1960) y un examen de práctica con corrección inmediata.

| Materia | Carpeta |
|---|---|
| Escatología (Teología Sistemática) | [`escatologia/`](escatologia/) |
| Libro de Daniel | [`daniel/`](daniel/) |

Para agregar una materia nueva: crea una carpeta con su `index.html` y añade una tarjeta en el `index.html` de la raíz.
